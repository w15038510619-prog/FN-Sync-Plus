### 1.2 历史容量管理（只读）

`Services/BackupCapacityAnalyzer.cs`：

- 当前备份 / 历史版本 / 物理对象 / 未被任何已提交版本引用的对象；
- 已提交版本数、最近版本时间、Top 20 大文件（含历史来源标记）；
- 引用缺失检测：清单引用的对象在存储中不存在时给出明确提示并标记不一致；
- 保留策略**预览**：保留最近 N 个版本 + 保留天数 + 可选历史上限；
  - 最新版本永不进入删除建议；
  - 版本记录损坏时返回 `Safe=false` 并给出阻止原因；
  - 明确说明「删除旧版本记录通常不会释放空间」，因为当前清单的历史记录仍引用旧对象。

**没有任何删除 API**，与「引用完整性和恢复安全充分验证前不得自动删除」的要求一致。

界面：设置页「备份容量与保留策略（只读）」卡片，可选任务、统计、预览。

**验证**：`--capacity-tests` 10 PASS / 0 FAIL（本地模拟 NAS，只读、孤立对象保留、重复执行不变）。

- **PASS，真实飞牛及部分 WinUI 操作：**一次自动监听、一次定时检查、正常退出重启后的补扫，以及仅移除任务配置。它们是有限场景的验证，不代表任何断电或跨设备故障都安全。

## 未执行或仍有限制

- **SKIP：**另一台实体 Windows 电脑上的恢复；当前没有第二台电脑。本机独立进程恢复不计为异机通过。
- **PASS，本地隔离回归（恢复目标链接）：**恢复目标路径经过联接点时会逐文件报告失败并拒绝写入，测试范围外未产生文件；并发替换文件系统链接的竞态与异机场景仍未验收。
- **SKIP：**NAS 断电、整机断网和跨设备并发安全的真实设备验收；上传及物理发布每个阶段的托盘退出也未全部覆盖。
- **使用边界：**用户确认同事各用自己的账号和独立备份目录，不需要多人共同写入一个目标。飞牛旧客户端或其他设备的写入无法由此程序全面识别，跨设备写入保护也未验证；每个备份目标仍需确保只有一个写入者。
- **账号限制：**新任务按账号名、设备地址及创建时的权威 UID 保守匹配，重新登录需保持账号名大小写一致且 UID 一致；UID 不一致或未知时停止任务。旧任务没有 UID 字段，仍只按名称和地址匹配；删除账号后用相同名称重建是否得到新 UID、以及不同真实账号的交叉验证尚未在设备上执行。
- **未完成：**旧任务不会自动迁移，新版配置与旧版分开。旧 v3/v4 清单的部分迁移仅经隔离原型和测试验证，不能保证任意旧备份均可自动迁移；原备份应保留。
- **待目视验收：**模糊重命名现在会在任务详情对话框顶部列出原备份文件、候选新文件和无法配对的新增文件，并说明上一份备份未改变；程序仍会停止该次备份且不自动猜测配对。该提示已在本地回归和新版引擎中验证，尚未在真实界面上目视查看。
- **有限制：**日志写入失败时暂存内存并提示，退出可重试；强制结束或断电仍可能丢失未落盘日志，大量持续失败会增加内存占用。
- **有限制：**新版试验配置的手动镜像已在独立配置及真实沙盒验证，对应正式默认配置的界面尚未验收；自动镜像不支持。

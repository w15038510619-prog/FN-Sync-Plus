# FN Sync Plus 双账号隔离与权限边界测试说明

本说明面向参与飞牛 fnOS 双账号隔离验收的测试人员。

---

## 一、双账号测试背景与安全要求

企业环境中，不同部门或同一设备的不同使用者可能连接不同的飞牛 NAS 账号。FN Sync Plus 必须确保：
1. **真实 UID 权威绑定**：UID 必须来自服务端真实响应，不同账号的 UID 必须不同；
2. **账号切换 Worker 关断**：切换登录账号后，原账号正在运行或排队的后台上传与同步任务必须**立即强制终止**，绝不串传；
3. **Token 作用域锁定**：旧账号的 Access Token / Cookie 严禁用于新账号的任务或目录，跨租户请求必须被客户端和服务端双向拦截；
4. **同名任务物理隔离**：若账号 A 与账号 B 都在本地创建同名备份任务（如“工作资料”），其在飞牛 NAS 上的存储路径必须为独立物理隔离目录（如 `我的文件/UID_A/工作资料` vs `我的文件/UID_B/工作资料`），绝对互不干扰；
5. **严禁破坏探测**：严禁对另一个账号的数据发起写操作、重命名或删除请求。

---

## 二、测试凭据安全规范

为防止测试凭据泄露，本工具执行如下严格保护策略：
- **安全交互式输入**：脚本默认通过交互式窗口接收密码，采用 Windows `SecureString` 内存加密，绝不将明文密码作为命令行参数传递；
- **日志零泄露**：终端输出、测试报告及持久化日志中绝不记录密码、Token 或敏感 Cookie；
- **会话结束自动清理**：测试完成后，内存中临时凭据变量立即置空释放。

---

## 三、实测操作步骤

### 1. 准备工作
- 确保测试机器能连通飞牛 NAS 局域网或内网地址（如 `http://192.168.1.100:8000`）；
- 准备两个**已授权的独立测试账号**（例如 `test_user_a` 与 `test_user_b`）。

### 2. 执行交互式测试
打开 PowerShell，运行以下命令：
```powershell
cd D:\FN_Sync_Plus_WB
.\tools\acceptance\Test-DualAccountAcceptance.ps1 -Interactive
```

### 3. 输入参数
根据屏幕提示依次输入：
1. `请输入飞牛 fnOS API 终端地址`: 例如 `http://192.168.1.100:8000`
2. `请输入测试账号 A 用户名`: 例如 `test_user_a`
3. `请输入测试账号 A 密码`: （密码输入时屏幕展示为掩码字符）
4. `请输入测试账号 B 用户名`: 例如 `test_user_b`
5. `请输入测试账号 B 密码`: （密码输入时屏幕展示为掩码字符）

### 4. 自动化执行与报告
脚本将自动调用底层正式 `FnOsApiClient` 与 `FnOsPersonalStorageProvider` 完成：
- 账号 A 登录并获取真实权威 UID；
- 账号 B 登录并获取真实权威 UID，校验 `UID_A != UID_B`；
- 模拟切换，验证账号 A 后台 Worker 立即停止；
- 校验 Token 作用域锁定（跨租户请求被拒绝）；
- 校验同名任务远端路径完全隔离。

执行完毕后，结果将自动生成至：
[docs/dual-account-acceptance-report.md](file:///d:/FN_Sync_Plus_WB/docs/dual-account-acceptance-report.md)

## 四、未提供双账号时的合规声明（BLOCKED）

若当前环境未提供第二套物理真实授权凭据，直接运行脚本将自动执行内置沙盒逻辑套件 `AccountIsolationTestSuite`（13 项全通过），并诚实将物理实体项标记为 **BLOCKED**。  
**企业发布合规准则严格禁止拼接虚假 UID（如 `uid-real-xxx`）伪造全 PASS 报告。**

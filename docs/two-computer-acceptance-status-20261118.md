## 收尾所需的现场工作

两边各运行一次 Run、一次 Peer。Run 在各自新建合成目录验证当前及历史内容，主要证明两账号的归属和相互独立。A 再补安装版暂停、断连、授权切换及重连的观察，B 只需确认本机配置独立。偶发 Token 过期等未出现条件如实记 BLOCKED，已有自动化未知提交、租约、回滚证据继续复用。

操作见 [双电脑剩余验收操作](two-computer-operator-guide.md)。结果由 `Merge-TwoComputerReports.ps1` 汇总，实际 FAIL 必须附原因和重现过程。通过汇总后可结束本轮必要实测，转入缺陷集中整改。后续每版按改动范围执行专项测试，一台先行试点机验证真实升级。

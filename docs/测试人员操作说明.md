# FN Sync Plus Beta 测试人员操作说明

本包用于小范围试用。每位测试人员使用自己的飞牛账号和独立备份目录。请先用合成样本完成一次备份和恢复。

## 1. 解压并安装

1. 将整个 ZIP 解压到普通本地文件夹。之后的路径都以这个解压目录为起点。
2. 双击 `installer` 文件夹里的 `FN-Sync-Plus-Beta-Pilot-Windows-x64-Setup.exe`。按提示安装并从开始菜单打开 FN Sync Plus。此包使用当前用户安装。
3. 在空白 Windows 测试环境先观察软件能否打开。使用日常电脑时，若已装其他版本，先记录版本与现有任务并向交付人确认升级方式。
4. 在 PowerShell 中切换到解压后的 `acceptance` 文件夹，运行：

   ```powershell
   .\FNSyncPlus.AcceptanceRunner.exe --help
   .\FNSyncPlus.AcceptanceRunner.exe --version
   .\FNSyncPlus.AcceptanceRunner.exe --test-restore-conflict-engine --mode LocalFixture
   .\FNSyncPlus.AcceptanceRunner.exe --test-dual-account-live
   ```

   在资源管理器进入 `acceptance` 后，可在地址栏输入 `powershell` 并按回车。验收工具无需源码、Git、.NET SDK 或管理员权限。上面最后一条是离线预检，应返回 BLOCKED。

## 2. 现场验收

- 使用合成样本验证普通文件、超长中文文件名、空目录和历史版本。第二台 Windows 电脑将当前文件和所选历史版本还原到两个不同目录，再分别校验。见 [异机恢复验收说明](异机恢复验收说明.md)。
- 两个授权测试账号的检查由交付人协调。每人日常使用自己的账号与目录。见 [双账号测试说明](双账号测试说明.md)。
- 记录安装、启动和恢复结果。恢复失败时在「恢复文件」点击「导出报告」，并保留校验工具显示的结果。见 [问题反馈模板](问题反馈模板.md)。

验收输出包含测试等级与结果。进程退出码 `0` 为 PASS，`1` 为 FAIL，`2` 为 BLOCKED，`3` 为 SKIP。PASS 只适用于对应行的测试等级。请提供本次 ZIP 的 SHA-256 和 `--version` 显示的构建 SHA，便于核对版本。

| 验收项 | 期望行为 | 验证方式 | 状态 | 诊断与结果说明 |
| :--- | :--- | :--- | :---: | :--- |
| **普通用户安装（非提权）** | 安装到用户私有目录（`%LOCALAPPDATA%\Programs\FNSyncPlus`），不弹 UAC 提权窗口 | Inno Setup `PrivilegesRequired=lowest` 编译验证 | **PASS** | `installer-acceptance.ps1` 验证通过，无需管理员权限 |

| **卸载后再次全新安装** | 卸载后能再次成功安装，自动继承并读取已有数据 | 卸载后重新调用安装包，检查版本状态 | **PASS** | 状态检查返回 Code 0，版本准确对应 |

## 二、界面多 DPI 与显示适配矩阵

| 验收项 | 期望行为 | 验证环境要求 | 状态 | 诊断与结果说明 |
| :--- | :--- | :--- | :---: | :--- |
| **100% 基础缩放 (96 DPI)** | 界面元素字体锐利，布局不重叠，长文件名适度截断并保留 Tooltip | 默认 Windows 显示输出 | **PASS** | WinUI 3 基础渲染正常 |

| **200% 超高清缩放 (192 DPI)** | 图标矢量无虚焦，长中文路径自动折行或提供水平滚动支持 | 需 4K 监视器真实缩放环境 | **BLOCKED** | **受限环境禁止强制修改宿主桌面 DPI 设置** |

## 四、安全边界与受限声明

- 根据企业安全准则，严禁通过 Windows API 强行更改宿主桌面全局分辨率或 DPI 缩放配置。
- 因此，物理实体 125%、150%、200% 的多屏幕真实截屏比对如实标记为 **BLOCKED**，待进入企业试点阶段由 QA 在真实多监视器笔记本及 4K 屏设备上实机点检。

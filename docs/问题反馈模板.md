# FN Sync Plus Beta 问题反馈模板

- 测试日期与大致时间
- Windows 版本与架构
- 应用版本、测试 ZIP SHA-256、验收工具 `--version` 的构建 SHA
- 涉及的场景，例如安装、长文件名备份、异机恢复、冲突跳过、双账号检查
- 连接方式，例如飞牛个人空间或 SMB
- 复现步骤，每行一个操作
- 预期结果和实际结果
- 显示的错误、退出码及 JSON 中对应的 TestId、TestLevel、Status、Reason
- 结果截图或有关证据，记录是否使用第二台 Windows 电脑

发送前请遮掉真实账号名、地址、路径、Token、Cookie、密码和验证码。可将测试目录替换为 `Codex_FN_Test_…`，基线文件包含相对路径，通常只需提供脱敏后的结果。保留失败时的测试备份供交付人查看。

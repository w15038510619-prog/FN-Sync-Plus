## 二、v2.1 全新产品特性与核心架构升级

### 1. NAS 私人空间深度支持（我的文件 / 个人空间）
- **告别被迫使用团队共享**：彻底打破以往只能默认列出或被迫选择团队共享（如 `\\server\团队文件-cenco-public`）的局限。
- **fnOS 权限与存储机制适配**：深入适配飞牛 Linux Samba 存储结构（个人主目录 `home` / `homes/<username>` / `username` / `我的文件` / `个人空间` / `私人备份`）。
- **分类展示与私人优先**：在 NAS 浏览器中将共享明确划分为【私人空间 (优先推荐)】与【团队共享】。
- **友好配置指引**：若当前 NAS 尚未开启个人主目录的 SMB 访问权限，系统主动提供清晰的管理后台配置指引，绝不强迫用户把个人数据同步至团队公用目录。

### 2. 自动创建同名文件夹（Auto-plan Destination Subfolder）
- **零手动路径输入**：在 Windows 选择本地文件夹（如 `D:\工作资料`），程序自动规划 NAS 目标子目录：`\\NAS\私人备份根目录\工作资料`。
- **智能防冲突与去重建议**：若目标目录已存在外来数据或属于其他任务，自动生成 `工作资料_2` 去重建议并提示用户；若包含相同的任务清单则智能复用历史数据。
- **浏览时不产生垃圾**：仅在用户最终确认“完成创建”时才在 NAS 上真正创建文件夹，纯浏览时绝不生成多余的空目录。

### 3. 现代化多任务独立调度架构（Multi-task Architecture）
- **多文件夹独立管理**：每个本地受保护文件夹为一个独立的 `SyncTask`，拥有独立的任务名称、源路径、NAS 目标、独立监控、运行状态与独立日志。
- **全局并发与队列调度**：基于 `SemaphoreSlim` 实施全局并发控制（支持自定义最大并发任务数），任务超出并发上限时自动入队排队执行。
- **独立文件变动监控**：为每个任务独立分配 `FileSystemWatcher`（包含 2.5 秒防抖合并与监控缓冲区溢出自动增量重扫）。
- **任务安全隔离与防重叠**：严格禁止本地源文件夹相互嵌套包含，严格禁止 NAS 目标目录相互重叠，确保不同任务的数据互不干扰。
- **无损平滑迁移**：自动将旧版本 v1.0/v2.0 的单任务配置平滑迁移为多任务模型的首个任务，配置零丢失。
- **安全删除原则**：删除任务仅删除本机调度与监控配置，绝对不破坏本地源文件或 NAS 已有备份数据。

### 4. 现代 Windows 11 Fluent 桌面 UI
- **全新首页状态总览**：顶部 NAS 实时连接状态胶囊、浅色/深色主题一键切换、一键“添加文件夹”向导、分段式导航（同步任务 / 恢复中心 / 设备连接 / 系统设置）、受保护任务统计条。
- **3 步添加文件夹向导**：
  1. 选择或拖拽本地文件夹（支持同时批量添加多个文件夹）。
  2. 选择 NAS 备份根目录（优先推荐私人空间）。
  3. 智能同名规划与防冲突预览，一键完成创建并启动首次同步。
- **多任务卡片流**：直观展示任务运行状态（待命/排队/扫描/同步中/完成/异常/离线等待）、实时进度百分比、传输速度、详细统计（扫描/上传/跳过/超长/失败/字节数）、立即同步/暂停/日志/配置/删除按钮。
- **独立任务日志视窗**：每个任务均拥有专属的实时日志流，支持日志搜索、清空与一键导出。
- **多任务智能发现恢复中心**：无需依赖旧电脑的本地数据库，直接扫描 NAS 根目录下由任意电脑或任务创建的备份包，一键还原任意指定任务。

### 5. 完整继承 v2.0 全部硬核文件系统可靠性
- **255 字节超长中文文件名与目录无损映射**：超过 255 UTF-8 字节自动转为 `_FN_LONG_*.ext`，普通文件 100% 保持原名。
- **专有命名空间元数据隔离 (`.fnsync/`)**：清单、暂存分块、并发锁统一隔离在 `.fnsync/` 目录中，严防备份数据被二次扫描。
- **固定短随机名暂存 (`stg_{guid}.tmp`)**：暂存文件统一使用约 20 字节短名称，彻底根治临界 254/255 字节长文件名暂存时的 1018 溢出报错。
- **恢复中心 SHA-256 强校验防御**：恢复时若文件哈希与清单记录不符，立即彻底删除损坏临时文件并记为失败，坚决杜绝坏数据充数。
- **空目录完美记录与还原**：自动记录并无损还原多层嵌套空目录。

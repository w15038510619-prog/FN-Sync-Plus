# 飞牛同步增强版 (FN Sync Plus) v2.0

> Windows 10/11 64位 独立单文件版长文件名兼容同步与异机恢复系统  
> 专为飞牛 NAS（fnOS）用户解决 Windows 超长中文文件名 `上传-文件名过长 (failed_code: 1018)` 痛点

## 核心技术特性与 v2.0 严重缺陷修复

### 1. NAS 文件夹浏览器交互全面修复
- **共享与子目录无缝新建**：彻底消除旧版本「请先双击进入具体的 NAS 共享目录后再新建子文件夹」的阻断弹窗。在根层级选中任意共享，点击「新建文件夹」即可自动绑定该共享并直接创建子目录。
- **目录名合法性校验**：实时拦截包含 `\ / : * ? " < > |`、末尾带空格或句点、保留设备名（`CON`, `AUX`, `PRN`, `COM1-9`）及 UTF-8 超过 255 字节的非法目录名。
- **SMB 写入权限预检与诊断**：新建前主动探测权限，权限不足时给出清晰友好的指引（提示在 NAS 管理后台为账号开通读写权限）。
- **新建后自动定位**：文件夹创建成功后自动刷新列表，并高亮自动选中新创建的目录。

### 2. 内部文件严格隔离，防止备份污染 (P0)
- **专有命名空间 `.fnsync/`**：NAS 目标备份目录下的清单、暂存分块、并发锁统一隔离在 `.fnsync/` 目录中：
  - `.fnsync/manifest.json`：元数据清单
  - `.fnsync/staging/`：传输暂存目录
  - `.fnsync/sync.lock`：多任务排他锁
  - `.fnsync/manifest.json.bak`：断电自动恢复备份
- **无限循环与自身嵌套拦截**：严格阻止源目录与目标目录相同、目标嵌套于源内部或源嵌套于目标内部；对 Windows 软链接、Junction 与映射驱动器进行规范化判定。
- **双向无损**：本地 Windows 源数据绝对不作任何修改，NAS 历史文件与未知文件绝对不随意删除。

### 3. 临时文件固定短名称暂存，彻底根治 255 字节溢出 (P0)
- **根治 1018 报错**：旧版本在原文件名后追加 `.fn_part_{GUID}` 导致 230 字节以上的临界文件名在上传时超出 Linux 255 字节上限。
- **固定短随机名**：所有分块上传统一在同文件系统的 `.fnsync/staging/` 中以 `stg_{Guid:N}.tmp`（约 20 字节）暂存，校验通过后原子覆盖到目标路径。
- **启动自动清理**：自动清理 1 小时以前的异常中断残留暂存文件。

### 4. 清单持久化与异机恢复强可靠性 (P0)
- **清单历史永不丢失**：当某个文件同步失败或用户手动取消时，历史清单记录与已成功项 100% 完整保留，杜绝清单被局部结果冲掉。
- **SHA-256 强校验防御**：恢复中心恢复文件时，先写至临时文件并实时计算 SHA-256。若与清单记录不符，**立即删除损坏临时文件，记录失败，严禁计入成功**，绝不把坏数据当成好数据。
- **空目录完美恢复**：自动记录并无损还原所有空目录层级。
- **跨目录穿越（Path Traversal）安全拦截**：对相对路径执行严格过滤，彻底杜绝包含 `..`、绝对路径或盘符的恶意清单项。

### 5. 并发控制与稳定性保障 (P1)
- **并发锁串行化**：通过 `SemaphoreSlim` 确保手动同步与后台自动轮询排队串行，避免多线程写入冲突。
- **文件被占用安全处理**：当文件正在被 Office 或其他程序写入时，以共享读安全探测并捕获锁定异常，记录友好提示并自动排队至下次重试，绝不崩溃。
- **监控缓冲区溢出自动恢复**：当本地大量文件变动导致 `FileSystemWatcher` 缓冲区溢出时，自动触发全量增量重扫，确保零漏单。
- **SMB 凭据冲突安全处理**：遇到 Windows Error 1219 时优先复用当前有效连接，绝不强行断开用户的其他网络盘符。

### 6. 现代 Windows 11 Fluent 桌面 UI
- **仪表盘与状态指示**：直观展示 NAS 连接状态、账号与 IP。
- **左右对称同步配置**：左侧本地源、中间备份流向与策略、右侧 NAS 目标，支持「📊 分析变动 (Pre-sync Analysis)」，在同步前清晰掌握新增、修改、跳过与超长名数量。
- **资源管理器级 NAS 浏览器**：地址栏、返回上一级、刷新、新建文件夹、权限状态指示灯。
- **分步式恢复向导**：检查清单预览 -> 选择本地目标与重名策略 -> 启动完整性恢复。

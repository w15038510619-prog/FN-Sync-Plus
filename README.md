# 飞牛同步增强版 (FN Sync Plus)

Windows 10/11 64位 独立单文件版长文件名兼容同步系统

## 核心交付文件

1. **`FN_Sync_Plus.exe`**：Windows 10/11 64位 独立免安装程序（已内置所有运行库，双击即用）
2. **`使用说明书.md`**：完整使用说明、逆向分析结论与测试报告
3. **`FNSyncPlus\`**：完整项目源代码（包含 C# WPF 界面、核心引擎与单元测试）
4. **`FNSyncPlus\build.bat`**：一键重新编译与打包脚本

## 核心特性

- **长文件名无损映射**：普通文件保留原名，仅 >255 UTF-8 字节文件自动短别名映射
- **异机一键无损还原**：更换电脑后，仅需连接 NAS 即可一键恢复所有原始超长名称与目录结构，SHA-256 完整性校验 100% 通过
- **解决 SMB 认证与错误 1219**：内置独立登录与凭据认证，支持可视化浏览 NAS 共享及子文件夹，支持在线新建文件夹
- **自动增量同步**：文件新增/修改自动上传，未修改秒级跳过，支持实时变动检测与定时轮询
- **开机自启与系统托盘**：关闭窗口最小化至系统托盘，后台持续守护备份
